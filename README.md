# Tab Hibernator

A privacy-first Manifest V3 Chrome extension that reduces memory use by unloading inactive tabs.

## Included

- Automatic hibernation after a configurable idle period
- One-click hibernation from the popup or right-click menu
- Per-site protection list
- Pinned tabs, audible tabs, and unsaved form changes protected by default
- Settings are synced with Chrome storage

## Install locally

1. Clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked** and select this project folder.

The extension relies only on Chrome extension APIs and does not send browsing data to any external service.
